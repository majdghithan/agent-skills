# Laravel 8 -> 9

**PHP floor: 8.0** (bump and deploy PHP 8.0 under Laravel 8 first, confirm green, then upgrade).

Laravel 9 was the big dependency jump. Most of the pain is not Laravel code, it is the libraries under it moving major versions at once.

## The runtime bites (not loud in the rename list)

- **Swift Mailer is gone, replaced by Symfony Mailer.** This is the one that surprises people. If you passed Swift-specific options, used `Swift_Message` directly, or leaned on a mail plugin built for Swift, it breaks. Custom transports and message tweaks need rewriting against Symfony Mailer. Plain `Mail::to()->send()` is fine.
- **Flysystem 3 fails writes SILENTLY differently.** Two behavior changes bite: cached adapters were removed (delete that config), and a failed write no longer throws, write operations now overwrite existing files and a failure returns false instead of raising. Code that assumed an exception on failure will sail past a broken upload. Check every `Storage::put` you relied on throwing.
- **Symfony 6 return types.** `getSession()` now returns a `SessionInterface` or throws when there is no session, rather than returning null. Any code that null-checked the session needs a look.

## The nice new thing (optional, do not rush it)

Laravel 9 added single-method accessors/mutators via `Illuminate\Database\Eloquent\Casts\Attribute` (type-hint the return). The old `getFooAttribute` / `setFooAttribute` still work, so this is a refactor you can do later, not part of the upgrade. Do not convert them all during the version bump, that mixes two changes.

## Also

- Implicit route binding now works with Enums (feature, not a break).
- Carbon stays on 2.x here, the Carbon 3 forcing comes at 12.
